# 快速验证指引: TextActions 工具栏与输入栏交互优化

## 前置条件

1. 在仓库根目录和 `frontend/` 目录分别执行 `npm install`
2. 启动前端开发服务器: `cd frontend && npm run dev`
3. 确保至少有一条含文本的记录

---

## 验证步骤

### 1. 工具栏按钮排列 (SC-001 / SC-002 / SC-003)

- 打开任意记录，观察顶部工具栏
- **重命名** / **翻译文本** / **分隔线** / **删除** 从左到右紧凑排列
- 删除按钮使用红色边框与文字，与普通按钮有明显颜色差异
- 点击"翻译文本"后，"显示翻译"复选框出现在按钮组右侧，无布局跳动

### 2. 现有功能完整性 (SC-004)

- 点击"重命名"→ 弹出对话框 → 输入新名称 → 确认成功
- 点击"删除"→ 弹出确认对话框 → 确认删除 → 记录被移除
- 点击"翻译文本"→ 翻译完成后勾选/取消"显示翻译"→ 翻译行正常切换

### 3. 内联句子操作 (SC-005 / SC-006)

- 点击任意句子，句子高亮并在其下方出现操作按钮行：**分析句子** / **取消**
- 若已有分析结果，额外显示 **删除分析** 按钮
- 开启"显示翻译"后选中句子，按钮出现在翻译文本下方，不遮挡翻译内容

### 4. 取消选择交互 (SC-007)

- 方式一：点击内联 **✕ 取消** 按钮 → 句子取消选中、按钮行消失
- 方式二：再次点击已选中的句子 → 同样取消选中

### 5. InputBar 自适应高度 (SC-008 / SC-009)

- 在底部输入框中输入 1-2 行文字 → 高度自动增长
- 继续输入至超过 7 行 → 高度锁定在 220px，出现垂直滚动条
- 发送文本（Enter）→ 输入框立即恢复默认最小高度，无残留滚动条
